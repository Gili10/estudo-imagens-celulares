# Estudo Comparativo de Redes Neurais Convolucionais para Detecção de Contaminação em Imagens de Células Sanguíneas

## 📋 Sobre o Projeto
Este trabalho compara diferentes modelos baseados em Redes Neurais Convolucionais (CNNs) com o objetivo de identificar aquele que apresenta o melhor desempenho na classificação de imagens celulares quanto à presença de contaminação.

**Conjunto de dados utilizado:** *"Cell Images for Detecting Malaria"* — Kaggle
- **Total de imagens:** 27.558
- **Células parasitadas:** 13.779 (50%)
- **Células não parasitadas:** 13.779 (50%)

## 💻 Tecnologias Utilizadas
- **Python 3** — Linguagem de programação
- **TensorFlow / Keras** — Construção e treinamento de Redes Neurais Convolucionais
- **OpenCV** — Leitura e processamento de imagens
- **NumPy** — Processamento de dados numéricos
- **Matplotlib** — Geração de gráficos e visualizações

## 📊 Metodologia
A pesquisa segue quatro etapas principais:
1. **Seleção e preparação** do conjunto de dados
2. **Pré-processamento** das imagens (redimensionamento, normalização)
3. **Implementação e treinamento** de diferentes arquiteturas de CNNs
4. **Avaliação comparativa** por meio das métricas: Acurácia • Precisão • Recall • F1-Score
